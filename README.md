# KarmiQ — Job Portal

KarmiQ is a web-based job portal designed to connect job seekers with employers through a simple platform for discovering, posting, and managing job opportunities.

## 🚀 Features

* User registration and login
* Job seeker and employer roles
* Job posting and management
* Job search and browsing
* Job application system
* User profile management
* Admin management

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mt4236/KarmiQ-job-portal.git
```

### 2. Move the project

Place the project inside your XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\KarmiQ
```

### 3. Start XAMPP

Start:

* Apache
* MySQL

### 4. Configure the database

Create the required MySQL database and import the project's SQL file.

### 5. Run the application

Open:

```text
http://localhost/KarmiQ/
```
